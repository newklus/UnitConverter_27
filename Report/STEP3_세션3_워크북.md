## README 자릿수 충돌 — 세션 3 Rule 해석 (1문단)

README는 **세 레이어**를 한꺼번에 적어 두어 충돌처럼 보인다: ① **출력 예시** `meter:2.5` → `8.2 feet`, `2.7 yard` (**소수 1자리**) ② **비즈니스 상수** `3.28084`, `1.09361` (**소수 5자리**) ③ **「정확히 계산」** (표시·TC 자릿수 **미명시**). 세션 3 Rule로 **한 줄 고정**한다:

> **내부 계산**은 README 상수 **풀 정밀도** · **화면 출력**은 README 예시와 동일 **소수 1자리 반올림** · **pytest**는 케이스별로 **표시값 TC**와 **내부 정밀도 TC**를 구분해 명시한다.

| 레이어 | 규칙 | 예 (`meter:2.5`) | 예 (`meter:1`) |
|--------|------|------------------|----------------|
| 상수 | `1 m = 3.28084 ft`, `1 m = 1.09361 yd` | 그대로 사용 | 그대로 사용 |
| 내부 | float 풀 계산 | 8.2021 ft, 2.7340… yd | 3.28084 ft, 1.09361 yd |
| 출력 | **소수 1자리** | `8.2 feet`, `2.7 yard` | `3.3 feet`, `1.1 yard` |
| TC (표시) | README 예시 정합 | feet=8.2, yard=2.7 | feet=3.3, yard=1.1 |
| TC (정밀) | 상수×값 | feet≈8.2021 | yard→m≈0.9144 (교재) |

**「`단위:값` 한 번 입력으로 meter/feet/yard를 README 상수 기준에 맞게 계산하고, 출력·검증 자릿수 규칙을 고정한 뒤 같은 입력·같은 순서(`meter:1` → `yard:1`)로 재실행해 맞다/틀리다를 판정할 수 있게 한다.」**

*(OCP·YAML·CLI는 수단이 아니라 **판정 비용↓·재현↑**가 목적)*
