## 1. 요약

`/tdd-red` 커맨드로 **T1 RED**를 수행했다. `user_input=-1`(0보다 작은 meter 값)에 대해 `status="fail"`과 `failed_lines` fail 사유를 **tests SSOT**로 고정했고, `src/`는 수정하지 않았다. pytest 결과 **FAILED 1** — 스텁 `...`이 `None`을 반환해 `TypeError` (의도된 RED). `.cursor/commands/tdd-red.md` RED 절차(Phase·AAA·금지)를 따랐다.

### T1 테스트 본문 (SSOT)

```python
def test_t1_negative_input_fail():
    user_input = -1
    expected_failed_lines = [{"reason": "negative_input", "user_input": -1}]
    result = unit_convert(user_input)
    assert result["status"] == "fail"
    assert result["failed_lines"] == expected_failed_lines
```
