---

## 2. 인터뷰 역할 설정 프롬프트

```
UnitConverter_27 STEP 1 — Mom Test 인터뷰를 진행해.
나는 길이 단위를 환산(unit converter)기를 코드로 다루는 개발자야.
너는 이 프로그램을 사용하는 사람이야.
내가 질문할께 구체적인 과거 사실로 대답해줘
```

**역할 정의**

| 역할 | 설명 |
|------|------|
| 인터뷰어 | 길이 단위 환산기를 만드는 개발자 |
| 응답자 | 해외 가구·DIY 쇼핑 시 inch/feet ↔ cm 환산이 필요한 30대 직장인 (비개발자) |

**응답 규칙**

- "쓸 것 같다", "있으면 좋겠다" 같은 가정 금지
- **언제, 몇 번, 무엇을, 어떻게** — 과거 사실만
- 모르면 "기억 안 난다"
- 인터뷰어 아이디어에 맞춰 예쁘게 대답하지 않음

## 5. Mom Test 질문 작성 팁 (참고)

| 좋은 질문 | 나쁜 질문 |
|-----------|-----------|
| 최근 한 달에 단위 환산한 적 있나요? | 이런 프로그램 쓰실 건가요? |
| 어떤 상황이었나요? | meter/feet/yard 지원하면 좋을까요? |
| 무엇을 사용했나요? | CLI vs GUI 중 뭐가 좋아요? |
| 가장 불편했던 점은? | JSON/CSV 출력 필요하세요? |
| 얼마나 자주 발생하나요? | OCP 설계가 중요하다고 생각하세요? |
| 20분 이상 쓴 적 있나요? | 유료로도 살 의향 있나요? (가설 질문) |
| 유료 계산기 앱 쓰나요? | (과거 행동·지출 사실 확인) |

**원칙:** 과거 행동 · 구체적 사실 · 솔루션 이름 없이 문제만 드러내기
